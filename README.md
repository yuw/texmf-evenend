# evenend

LaTeXの段組（`\twocolumn`）で，最終ページの各段の下端を揃えるLuaLaTeX用パッケージ．
flushendと同じ目的のものだが，次の点を扱う．

- 3段以上の段組（`columns=3`など）
- 段内フロート（最右段に載ったものも含む）と段抜きフロート（上端・stfloatsによる下端）
- 脚注：既定では，multicolと同じく脚注を版面の全幅で組み，すべてのページで版面の下端に
  置く．カラム下端に置くこともでき，そのときは最終ページで参照位置が移った段へ脚注も移す
- 段をまたいで分割された脚注の再結合
- ページの途中での段数の切り換え（`\evenendcolumns{3}`など）．切り換えの前の段組も下端を揃える

行数によっては最右段だけが短くなる（たとえば2段で31行なら16行と15行）．それ以外の段は
下端が揃う．

詳しくは`doc/lualatex/evenend/evenend-ja.pdf`（マニュアル）を参照．

## 動作要件

- LuaLaTeX（LaTeX 2024-11-01以降）．TeX Live 2025（LaTeX 2024-11-01）とTeX Live 2026
  （LaTeX 2026-06-01）で動作を確認している．テストは環境変数`TLYEAR`（既定は2026）で
  TeX Liveの版を選べる（例：`TLYEAR=2025 test/run.sh …`）
- LaTeX標準の段組（クラスオプション`twocolumn`または`\twocolumn`）．multicolの
  `multicols`環境は対象外．
- jlreq，LuaTeX-jaのクラスで動作を確認している（横組のみ）．

## インストール

`tex/lualatex/evenend/`の`evenend.sty`と`evenend.lua`をTEXMFツリーに置く．
このリポジトリ自体をTEXMFHOMEとして使うこともできる．

```bash
export TEXMFHOME=/path/to/texmf-evenend
```

## 使い方

```latex
\documentclass[twocolumn]{jlreq}
\usepackage[footnote=column]{evenend}
```

読み込むだけで，文書末（`\end{document}`）と`\onecolumn`の直前のページが揃う．

### オプション

| キー | 値 | 既定 | 意味 |
|---|---|---|---|
| `columns` | 整数 | `2` | 段数．3以上なら段幅も`(\textwidth-(N-1)\columnsep)/N`に設定する（読み込み時のみ） |
| `footnote` | `page`／`column` | `page` | 脚注を版面の全幅で版面下端に置くか（multicolと同じ），各段の本文の下（カラム下端）に置くか |
| `onecolumn` | 真偽 | `true` | `\onecolumn`の直前のページも揃える |
| `enable` | 真偽 | `true` | 文書末のページを揃える |
| `blockskip` | 寸法 | `2\baselineskip` | 段数の切り換えの前後の行のベースライン間 |
| `blockgap` | 寸法 | 空 | 前の段組の下端から次の段組の上端までのアキ（multicolの`\multicolsep`と同じ測り方）．空でなければ`blockskip`の代わりに使う |
| `blockmin` | 寸法 | `5\baselineskip` | 切り換えの後に残った高さがこれより小さければ改ページする |
| `spanfootnote` | `above`／`bottom` | `above` | `footnote=column`で，下に段をまたぐ図がある段の脚注を，図の上に置くか，図の下に置くか |
| `headingskip` | `column`／`block` | `column` | 切り換えた後の段組が見出しで始まるときの見出しの上アキの扱い |
| `floatgrid` | 真偽 | `true` | フロートの前後の本文の行を行送りの位置に合わせる．evenendが組む段だけに効く（揃える最終ページとブロック，`footnote=page`ではすべてのページ．gyoudoriは要らない） |
| `gridreport` | `summary`／`page`／`none` | `summary` | `floatgrid`が効かないページ（evenendが組まないページ．`footnote=column`でLaTeXが組む満杯のページなど）で，フロートの後の行が行送りの位置からずれたとき，文書の最後に一覧を警告する（`summary`），ページごとに情報をログに書く（`page`），何もしない（`none`）．`debug`とは別 |
| `debug` | 真偽 | `false` | 段ごとの高さなどをログに書く |

`footnote=page`（既定）では，脚注を段に分けずに版面の全幅で組み，すべてのページで版面の
下端に置く（multicolと同じ）．段の高さは，版面からそのページの脚注の領域を除いた高さになる．
LaTeXが段を組むあいだは脚注の高さを段数倍で見込み，ページの最後の段でそのページの本文を
組み直す（入り切らない本文はその脚注とともに次のページへ送り返す）．最終ページでは，本文を
揃えた段組の下を空け，脚注は版面の下端に置く．`footnote=column`では，脚注を参照位置のある
段の下端に置き，最終ページでは脚注を含めた各段の下端が揃う．

オプションごとの組み方の違いは，マニュアルの「オプションの詳細」の節に見本の図で示す
（`evenend-sample-options.tex`）．

`columns`以外のキーは文書中でも`\evenendsetup{...}`で変えられる．

### 命令

- `\evenend`，`\raggedend`：文書末のページを揃えるかどうかを切り替える
- `\evenendclearpage`：いまのページを揃えてから改ページする（章末などに）
- `\evenendsetup{キー=値}`：オプションの変更
- `\evenendcolumns{段数}`：その位置から段数を変える（1も可）
- `\evenendcolumns[columnsep=寸法,columnseprule=寸法]{段数}`：その段組だけの段間と段間罫を
  指定して段数を変える
- `\evenendcolumns*{段数}`：段数を変えるが，その前のブロックは揃えない
- `\columnbreak`：そこで段を改める（揃えるページやブロックの中でも守る．段落の途中では
  その行の後で改める）
- `\evenendifpageempty{真}{偽}`：ページが空か（`\pagetotal`が0で，積んだ段組もない）で分ける
- `\evenendnewpage`：改ページする（積んだ段組だけのページでも改める）
- `spanfigure`，`spantable`環境：段をまたぐ段内フロート（`\begin{spanfigure}[b]{2}`など）

### 段をまたぐフロート

`\begin{spanfigure}[位置]{段数}`（表は`spantable`）で，3段組の2段ぶんのように，いくつかの段に
またがる段内フロートを置ける．

- 中身は，またがる段の全幅で組む（`\hsize`と`\linewidth`がその幅）．
- 置き方は通常の段内フロートと同じ（入る余地があれば書いた位置のページに置き，なければ送る）．
  置かれた段を左端にして右へ広がり，右端を越える段には置かない．
- 位置は`t`と`b`だけ（`h`，`p`は使わない）．上・下の領域の割合の制限は外す．
- 右の段には同じ高さの場所取りを置き，またがる段のあいだで位置をそろえる．段をまたぐフロートが
  横切る段間では，段間罫は両側の段の本文の領域だけに引く（フロートと\textfloatsepの部分には
  引かない）．罫の端は，両側の段のフロートに接する行の字面（字の輪郭から求める）にそろえる．段をまたがないフロートの横では，これまでどおり版面の高さいっぱいに引く．
- クラスの`figure`，`table`環境を呼ぶので，その始まりの設定（キャプションのアキなど）が効く．
  下に置いたときは，またがる段の脚注をフロートの上に置く．`spanfootnote=bottom`にすると，脚注を
  図の下に置き，図をまたがる段のいちばん高い脚注の上にそろえる．最終ページとブロックでは，すべての
  段で脚注の下端を揃えた段の下端に置く．ほかのページでは脚注は版面の下端で，図の右の段の脚注は
  図の置かれた段の脚注の高さまでに収め，残りを次の段に送る．
- 同じ位置（上か下）では，1つの段に2つの段をまたぐフロートはかけない．
- 最終ページやブロックを揃えるときは，置かれた段に固定して揃える．
- 最終ページ（文書末，`\evenendclearpage`，`\onecolumn`の前）では，持ち越された段内フロート
  （段をまたぐものを含む）も揃える段組に入れてみる．入り切らなければ入れずに揃える．
- `\clearpage`のときに残っているものは，段抜きのフロートとしてフロートだけのページに出す．

### multicol互換の環境

multicolを読み込んでいなければ，`multicols`環境（終わりで揃える），`multicols*`環境
（揃えない），`\columnbreak`を用意する．`\begin{multicols}{3}[前置き]`の前置きは1段で組む．
multicolを読み込んでいても使える`evenendmulticols`環境
（`\begin{evenendmulticols}[columnsep=…,columnseprule=…]{段数}[前置き]`）もある．
組み方はmulticolと同じにする（段組の中の行分けの設定，前後の`\multicolsep`，
始めるときの`\premulticols`による改ページ，段の揃え方）．1段に戻るときの最後の1段の
段組は揃えずに中身のまま積む（脚注や段内フロートがあるとき，`floatgrid`で本文中のフロートや
高い箱があるときを除く）．
入れ子やリストの中では使えない．ページの本文では段組のモードで使うので，1段組の文書では
`\documentclass[twocolumn]{…}`と`\usepackage[columns=1]{evenend}`で読み込む．

### 箱の中の段組

tcolorboxの箱，`minipage`，`\parbox`，フロートの中など（内部垂直モード）では，`multicols`環境と
`evenendmulticols`環境は，出力ルーチンを使わずにその場で段組を組んで1つの箱にする（段組の
モードでない文書でも使える）．

- 中身を段幅で組み，multicolと同じ方法で各段に分けて揃える（段の高さと分け方はmulticolと
  同じ）．最右段と`\columnbreak`で終わる段は下を空ける．
- 前後にはmulticolと同じく`\multicolsep`を空け，前が行なら段組の1行目を前の行から行送りの
  倍数の位置に置く．箱の先頭では1行目の上端を箱の上端に合わせる．
- 箱の中の脚注は，その箱の脚注として箱の下に置く（`minipage`と同じ）．
- 段組は1つの箱になるので，分割できるtcolorbox（`breakable`）でも段組の途中では分けない．
- 入れ子はできない．`\evenendcolumns`は箱の中では使えない．

### 柱

段組のモードでは，柱（マーク）の情報をページを出力するときに1回だけ，ページの本文全体から
読む順序（ブロックは上から，段は左から，段の中は上から）で集めて更新する．揃えた段や積んだ
ブロックでも，柱の最初と最後のマークはそのページの本文の最初と最後のものになる．
LaTeX 2025-06-01より前の版（`\leftmark`，`\rightmark`がTeXの`\firstmark`，`\botmark`を
使う）では，集めたマークの最初と最後をそれらの代わりにする．

### 段数の切り換え

```latex
\section{2段}
...
\evenendcolumns{3}
\section{3段}
...
```

切り換えの位置までのそのページの段組（ブロック）を，最終ページと同じ方法で揃えて確定し，
その下に新しい段数で段組を続ける．1ページにいくつでもブロックを積める．

- 前のブロックの最終行から次のブロックの1行目までのベースライン間は`blockskip`．さらに，
  ページの残りの高さが行送りの位置で終わるように，アキを1行未満だけ広げる（行の位置が
  揃った組版では広げない）．
- ページの残りが`blockmin`より小さければ，そこで改ページする．
- 切り換えた後の段組が見出し（jlreqのように行取りした箱）で始まるとき，既定
  （`headingskip=column`）では段組の間は常に`blockskip`で，見出しの上アキは1段目の中に
  ある（他の段の1行目は段組の上端から始まる）．`headingskip=block`では，段組の中の組は
  そのままで，段組全体を見出しの上アキ（字面の上端が通常の1行目の上端より下がっている
  分．行送りの倍数に丸める）だけ下げる．2段以上の段組でも，段組と段組の間のアキが
  1段組に切り換えた場合（見出しの上アキが段組の間に見える）と同じ節のアキになる．
  ページの最初の段組と1段の段組には何もしない．
- ブロックがそのページに入り切らなければ，残りを次のページで揃えてから段数を変える．
- ブロックの脚注は，`footnote=page`ではページの脚注として版面の下端に全幅で置き（その分
  だけ後の段組の高さが減る），`footnote=column`ではそのブロックの段の下端に置く．
- フロートはそのブロックの中で完結させる．持ち越された段内フロートはそのブロックの段の上に，
  持ち越された段抜きフロートはそのブロックの下に段抜きで置く．入り切らなければ本文だけで
  揃えてページを終え，持ち越したフロートは次のページの上に元の段数のブロックとして置いてから
  段数を変える．持ち越された段内フロートを入れる前にフック`evenend/deferredfloat`を呼ぶ
  （`\evenendfloatbox`がその箱．gyoudoriなどが中身の位置を整えるのに使う．gyoudoriは
  v20261018.0から，`float`オプションのとき自分でこのフックに処理を入れる）．
- stfloatsがそのページの下端に予約した段抜きフロートも，切り換えのときにそのブロックの下に
  置く．ブロックを積んだページには，その後に現れた段抜きフロートを置かない（持ち越して，
  次の切り換えでそのブロックの下に置く）．
- 本文がなくフロートだけのブロックも，ブロックとして確定する．段より高いフロートがあって
  それも組めなければ，LaTeXのフロート段として元の段数のまま出してページを終え，残った
  フロート（`p`の指定がなくフロート段に置けないものなど）は次のページでもう一度ブロックに組む．
- 切り換えの直後に文書が終わっても，積んだブロックを出力する．
- 段組のモード（`twocolumn`）で使う．1段のブロックも`\evenendcolumns{1}`で作る．
  `\twocolumn`は読み込み時の段数で段組を始め直す．
- 段間（`\columnsep`）と段間罫の太さ（`\columnseprule`）は段組ごとに決まる．段組を始める
  ときの値をその段組で使い（ページをまたいでも同じ），途中で変えても次の段組から効く．
  `\evenendcolumns`の省略可能な引数`columnsep`，`columnseprule`はその段組だけの値．
  `multicols`環境は始まりのときの値を使い，終わりで環境の前の段組の値に戻す．

### フロートの前後の行の位置（`floatgrid`）

evenendが組む段では，行ドリしないフロートがあっても本文の行を行送りの位置に合わせる
（既定）．

- 上下のフロートの並び（フロートとアキ）の高さを行送りの倍数に切り上げ，足した分を本文との
  間のアキに加える．上のフロートと本文の間のアキは伸縮させない．
- 本文中のフロート（`[h]`）は，段に分けた後で，直後の行が段の行の位置（`\topskip`＋
  行送りの倍数）に乗るよう，前後のアキに半分ずつ足す（段の先頭のフロートは後ろだけ）．
  前後のアキは伸縮させない．段の末尾に来たときは，フロートの領域が行き着く次の行の字面の
  下端を段の下端とみなす．
- 材料がページに入り切らないときは，段下端の脚注の塊を行送りの倍数に切り上げるのをやめ，
  それでも入らなければ`floatgrid`をやめて揃え直す．

`floatgrid=false`で，これまでどおりアキを伸縮させて揃える．

## 仕組み

1. 各段を出力するとき（`\@makecol`の直前），段の生の材料（`\box255`），改段位置で捨て
   られるグルー類，脚注（`\box\footins`），段内フロートの複製をLua側にとっておく．
2. 脚注には番号を属性として付け，本文中の参照位置には同じ番号の印（`\vadjust`で
   行の直後に置くwhatsit）を置く．
3. 最終ページの最後の段が`\clearpage`の強制改段で出力されるとき，そのページの全段の
   材料を1本の垂直リストに繋ぎ直し，入り切る最小の段の高さを探して`\vsplit`で再分割する．
   脚注は参照位置の入った段に移し，その高さを段の容量から差し引く．
4. 段抜きフロートは`\@combinedblfloats`がこれまでどおり配置する．LaTeXがフロートだけで
   組んだ段（フロート段）も取り込み，その中身を上のフロートとして揃える段組に入れる．
5. 各段の見かけの下端をそろえる．本文で終わる段は最終行のベースラインに本文の行の標準の
   深さを足した位置，下のフロートで終わる段はフロートの下端を見る．段下端の脚注で終わる段は，
   脚注の最終行のベースラインを本文の段の最終行のベースラインに揃える．最後の箱の中身が
   箱の下端からはみ出している場合（中身をグルーで下へずらした箱など）は，はみ出した位置を
   下端とみなす．
6. 段内フロートは，番号順を保ったまま（前の段へは動かさずに），揃えた段の高さが最小に
   なるように段を選び直す．
7. 本文だけの満杯の段があればその段を基準にし，フロートのある段はフロートまわりの
   グルーの伸び縮みで合わせる（行の位置を揃えるため）．最右段やフロートのある段が
   基準より高くなった場合と，途中の段が明らかに短くなった場合は，段の高さを（段の高さ
   いっぱいまで）上げて分け直す．それでも揃わない途中の段は，次の段の先頭の材料が入らな
   かったものとして下を空ける．
8. 段数の切り換えでは，揃えた段組を1行の箱にしてページの上部に積み，`\@colht`を
   その分だけ減らして段組を続ける．ページを出力するときに積んだ箱を上に置く．

`footnote=page`では，最終ページ以外のページも，最後の段を出力するときに材料を繋ぎ直し，
版面からページの脚注の領域を除いた高さで分け直す．入り切らない本文は，その脚注を`\insert`に
戻して付け，出力ルーチンから主垂直リストへ送り返す．`footnote=column`では，最終ページ以外の
組版は，パッケージを読み込まない場合と変わらない．LaTeXが組んだ段が
はみ出す（Overfull）警告は，そのページを組み直さずに出力するときだけ出す．

## gyoudoriとの関係

evenendはgyoudori（行取りのパッケージ）に依存しない．gyoudoriを読み込まなくても，すべての
機能が使える．gyoudoriを併用したときに変わるのは次の点だけで，ほかは変わらない．

| 機能 | evenendだけ | gyoudoriを併用すると |
|---|---|---|
| 揃える，段数の切り換え，段をまたぐフロート，脚注，`footnote=page`のページの組み直し | evenendが行う | 変わらない（行取りした見出しやフロートの箱をそのまま材料として扱う） |
| 見出しの行取り（`headingskip`の前提） | クラス（jlreqなど）の見出しの箱を使う | 変わらない |
| evenendが組む段でのフロートの前後の行の位置 | `floatgrid`で合わせる | 行取りしたフロートは高さが行送りの倍数なので，`floatgrid`は何も足さずにそのまま使う |
| `footnote=column`でLaTeXが組む満杯のページでのフロートの前後の行の位置 | 合わせない（LaTeXのまま） | `float`オプションで行取りして合う |
| 持ち越されたフロートを揃える段組に入れるときの中身の位置 | 箱のまま上か下に置く | フック`evenend/deferredfloat`で，上のフロートとして行取りし直す |

## 制限事項

- 分割しない脚注が長くて，揃える段組がページの残りに入り切らないときは，揃えずにLaTeXの
  組み方に戻す（警告を出す）．
- jlreqでは，脚注と段内・段抜きフロートが同じ段に入ると，LaTeXが通常どおり組んだ段が
  わずかにはみ出すことがある（evenendを使わなくても起きる）．
- 揃える段組では，脚注は段をまたいで分割しない．
- 段内フロートは元の段かそれより後の段に置く．参照位置との前後関係は保証しない．
- `\marginpar`の左右は再計算しない．
- 縦組は未対応．
- `floatgrid`はevenendが組む段（`footnote=page`ではすべてのページ，`footnote=column`では
  揃える最終ページとブロック）だけに効く．`footnote=column`でLaTeXが通常どおり組む満杯の
  ページで，行送りの倍数でない高さのフロートの前後の行を合わせるには，gyoudoriでフロートを
  行ドリする（gyoudori併用時）．
- `footnote=page`でページの本文を組み直すとき，入り切らない本文は次のページへ送り返すが，
  LaTeXがそのページに置いた段内フロートはそのページに残す（参照位置より前のページに
  フロートが来ることがある）．段の高さより高い分けられない材料は，そのページにほかに何も
  なければ段からはみ出させて置き，そうでなければ次のページへ送る．
- `\evenendcolumns`はリスト環境などの中では使えない（段落の間で使う）．
- `\@outputdblcol`を再定義する他のパッケージ（flushend，balanceなど）とは併用できない．
  stfloats，tcolorbox（分割できる箱も），hyperrefは併用できる．tcolorboxの分割できる箱に
  キー`evenend breakable`を付けると，揃えるページで段の下端がそろう分け方を`.aux`に書き，
  次の組版で`break at`に渡す（`evenend min first=寸法`で最初の部分の最小の高さ）．

## テスト

`test/`にテスト文書と補助スクリプトがある（poppler-utilsの`pdftotext`などを使う）．

```bash
test/run.sh test/t1-basic.tex
```

- `run.sh`：リポジトリをTEXMFHOMEにしてLuaLaTeXを走らせる
- `suite.sh`：固定のテスト一式（`fuzz.sh`，`fuzzswitch.sh`，`fnfloat.sh`，`gy/sweep.sh`）をまとめて走らせる
- `colbottoms.py`：最終ページの各段の最下行の位置を表示する
- `fuzz.sh`：本文の長さを1文ずつ変えて組み，エラーと段の下端を調べる
- `fuzzswitch.sh`：段数の切り換えを含む文書をブロックごとの分量を変えて組み，エラー，
  Overfull，行送りの位置，ブロックごとの下端の揃いを調べる（`FIG=0`で図を入れない）
- `blockcheck.py`：`debug`のログから，揃えた段組ごとに下端の揃いを調べる
- `gridcheck.py`：本文の行が行送りの位置に乗っているかを調べる
- `fnfloat.sh`：同じ段にフロートと脚注が入る文書を，フロートの位置（上／下），脚注の置き場所
  （`page`／`column`），場面（最終ページ，段数の切り換え前のブロック，切り換えた後の最後の
  段組），本文の分量を変えて組み，配置を調べる（`fnfloatcheck.py`を使う）
- `fnfloatcheck.py`：字の重なりがないか，脚注が参照位置と同じ段の一番下にあるか，
  `footnote=page`の最後の段組で脚注が版面の下端にあるかを調べる
- `pagefncheck.py`：`fuzzswitch.sh`の文書で，途中のブロックの脚注がそのブロックの段の下に，
  最後の段組の脚注が版面の下端にあるかを調べる
- `gridoffset.py`：本文の行の行送りの格子からのずれ（外れた数，最大，平均）を測る
- `rand/`：乱数で作った文書による網羅テスト．`gen.py`（文書を作る），`check.py`（調べる），
  `one.sh`（1件），`many.sh`（並列で多数），`summary.py`（まとめる）．例：
  `test/rand/many.sh 1 1000 > result.txt; test/rand/summary.py result.txt`
- `tcb/`：tcolorboxの箱（分割しない箱，分割できる箱，フロートにした箱）との組み合わせ
- `mc/`：multicols互換の環境と柱（マーク）のテスト（`mkcheck.py`で柱を調べる）
- `span/`：段をまたぐフロート（上・下，最終ページ，3段にまたがるもの，脚注，gyoudori）
- `box/`：箱の中の段組（tcolorbox，minipage，フロート，脚注，`\columnbreak`，分割できる箱）
- `gy/`：gyoudori（行ドリ）の`float`オプションとの組み合わせの一括テスト（48通り）．
  `genf.py`（文書を作る），`chk.awk`（本文の行とフロートが行送りの位置にあるかを調べる），
  `runl.sh`（1件），`sweep.sh`（一括）．gyoudoriの置き場所は環境変数`GYOUDORI`で指定する．
  TeX Live 2025（LaTeX 2024-11-01）では，evenendを使わなくても下のフロートが行送りの位置から
  0.07行ずれる（gyoudori側の版の違い）ので，このテストはTeX Live 2026で使う．
  例：`test/gy/sweep.sh`
